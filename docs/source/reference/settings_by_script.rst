Settings by initialization script
=================================

Most of :doc:`sph_input` applies to every run: the timestep controls, the
equation of state and the output intervals are read by the integrator and
mean the same thing whatever ``INAME`` is set to.

The settings below are the exception.  Each is read only by the setup
routines listed, so setting one for any other script has no effect and
produces no warning.  This page is generated from the source, by looking at
which file actually mentions each variable.
