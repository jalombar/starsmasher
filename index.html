StarSmasher

A Smoothed Particle Hydrodynamics code for smashing stars (and planets)

View project on GitHub

StarSmasher is a smoothed particle hydrodynamics (SPH) code for modelling collisions and close interactions between stars and planets. It is parallelised with MPI, and computes self-gravity either on NVIDIA GPUs or, if you have no such card, on the CPU. It descends from StarCrash, written by Joshua Faber, James Lombardi and Frederic Rasio.

Please contact Jamie Lombardi (jamie.lombardi@allegheny.edu) with any questions.

Getting the code

git clone https://github.com/jalombar/starsmasher.git

StarSmasher is compiled against whatever MPI and CUDA your machine has, so clone the repository rather than downloading an archive: that way you can pull later fixes without starting again.

Documentation

The documentation lives in the repository, where it is kept current. Start here:

  • Installation guide — what you need, compiling the gravity library, and building the code
  • Star–star fly-by walkthrough — a worked example, from relaxing a single star to running the encounter
  • Example input files — ready-made setups for relaxations, collisions and binaries
  • Tips and tricks — advice on getting a simulation to behave
  • Data visualization — reading and displaying the output snapshots
  • User's guide — a draft covering the SPH background and the code's structure

What is in the repository

  • parallel_bleeding_edge — the current version of the code, and the one most people want
  • Blackollider — a variant for collisions involving compact objects treated as point masses
  • example_input — example input files
  • documentation — installation guide, walkthroughs and user's guide
  • Data_visualization and splot_routines — tools for looking at output
  • misc — assorted makefiles and the StarCrash manual

Papers and citation

The algorithms are described mainly in Gaburov, Lombardi & Portegies Zwart (2010), with the artificial viscosity scheme following Balsara (1995) and Ponce et al. (2011). A fuller list, including papers that have used the code, is kept in papers.md and publications.md.

If you publish work done with StarSmasher, please cite the relevant papers above. The code is released under the GNU General Public License v3.
